# Lesson 1.2 – Variable Assignment

## Overview

This lesson introduces variable assignment in Python and explains how Python binds variables to objects in memory.

- Variable Binding

- Chain Assignment

## Key Learnings

- Variables are references to objects.
- Assignment binds a variable to an object.
- Variables can be reassigned.
- Python supports multiple assignment.
- Python supports chain assignment.
- Python allows swapping variables without a temporary variable.
- Python can unpack lists and tuples into variables.
